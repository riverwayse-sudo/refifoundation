# REFI Foundation engineering standards

Use these documents during design, implementation, review, release, and maintenance.

| Document | Use |
|---|---|
| [ASD-STE100 policy](./ASD-STE100.md) | Write clear and consistent technical information. |
| [Terminology register](./TERMINOLOGY.md) | Use approved project terms. |
| [Engineering review checklist](./REVIEW-CHECKLIST.md) | Review implementation quality and release risk. |

## Required review flow

1. Define the problem and acceptance criteria.
2. Record relevant constraints and existing behavior.
3. Implement the smallest safe change.
4. Run the relevant automated tests.
5. Complete the engineering review checklist.
6. Review technical communication against the ASD-STE100 policy.
7. Verify user-visible behavior in the deployed environment.
8. Record remaining risks and owner actions.

This project policy is STE-aligned. It does not claim formal ASD-STE100 compliance. Formal compliance requires review against the complete current official standard.
